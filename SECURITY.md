# Security and privacy

This preview is for a single trusted operator. It is not a multi-tenant service and has not received an independent security audit. Bind to loopback; add your own authenticated TLS gateway before any remote deployment. Never expose the database directly.

Do not commit local environment files, credentials, exports, database dumps, logs, screenshots of real accounts, or downloaded advertising media. Runtime records and backups contain private business information even when no credentials are present.

Public preview guards refuse write-enabled startup and force the optional Meta adapter into read-only mode. Reports and suggestions never approve or execute platform changes. Use a token with only the permissions required to read your own authorized accounts.

For suspected vulnerabilities, avoid publishing secrets in a public issue. Contact the maintainer through the GitHub profile for a private reporting channel. Do not assume this file or the included scanner proves the absence of every vulnerability.
